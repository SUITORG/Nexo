SuitOS Commit. Primero pregúntale al usuario el tipo (feature|bugfix|docs|refactor|chore) y la descripción del commit. Ejecuta git status y git diff para revisar los cambios. Confirma con el usuario qué archivos incluir. Luego ejecuta git add -A (excluyendo secrets) y git commit -m "{emoji} {tipo}: {desc} (v{X.Y.Z})" desde WSL. El emoji debe corresponder al tipo: feature: ✨, bugfix: 🐛, docs: 📝, refactor: ♻️, chore: 🔧.
