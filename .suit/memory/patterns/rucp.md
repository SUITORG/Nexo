# RUCP — regla de trabajo del usuario (respuestas y código)

Fuente: instrucción original del usuario (2026-10-10). Complementada con la ampliación de "C" pedida por el usuario.

| Letra | Significado | Aplicación |
|---|---|---|
| **R** | **Reusar** código y funciones | Antes de escribir: buscar plantilla/helper/skill existente (`GuiaTotal/plantillas/`, skills, utils). RUCP = plantillas y encadenamiento, no reescritura. |
| **U** | **1% disruptivo** | Pensar el 1% de idea/mecanismo que cambia el resultado, no el 99% obvio. |
| **C** | **Compacto** | **Respuestas de 2-3 frases al explicar problemas o dar instrucciones — en español simple, sin relleno.** Tablas/código cuando ahorran líneas. (La instrucción original decía "contesta de manera compacta"; el usuario la amplió a 2-3 frases simples.) |
| **P** | **Pareto 20%** | Primer el 20% de esfuerzo que da el 80-100% del resultado; no ejecutar el resto sin confirmación. |

**Nota:** para entregables, reportes o walkthroughs pedidos explícitamente, el detalle se da completo — la C gobierna explicaciones e instrucciones, no los documentos que el usuario pidió.
