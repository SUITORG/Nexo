ViRe vs ViHy

Remotion vs HyperFrames — Mismo guion, misma imagen, diferente render

ViRe Remotion (React)
Stack: React + TypeScript + Remotion
Rendering: Remotion Renderer (custom)
Componentes: TextScene.tsx, IntroScene.tsx
Imagen: Pollinations (sin model param)
ViHy HyperFrames (HTML)
Stack: HTML + CSS + GSAP (vanilla)
Rendering: Headless Chrome + FFmpeg
Componentes: composition.html (data-* attrs)
Imagen: Pollinations (model=flux, photorealistic)

ViRe (Remotion)

~39s

ViHy (HyperFrames)

~39.7s

Lo que cambia

  • ViRe usa React components + Remotion bundler. La imagen se renderiza a opacity: 0.25 como fondo lavado.
  • ViHy usa HTML puro + CSS + GSAP. La imagen se muestra completa con gradiente oscuro solo detrás del texto.
  • Imagen: ViHy usa model=flux + prefijo "professional commercial photography". ViRe no.
  • Render: ViRe necesita Remotion Studio/bundler (~168ms/frame). ViHy necesita Chrome + FFmpeg (~168ms/frame). Tiempo similar.
  • Preview: ViHy puedes abrir vihy-project/index.html en cualquier navegador sin servidor.
  • Simplicidad: ViHy es HTML puro — sin React, sin TypeScript, sin build step. Un agente IA puede generarlo directamente.
  • Catálogo: ViHy tiene bloques reutilizables (transiciones, overlays, captions) listos para usar.
