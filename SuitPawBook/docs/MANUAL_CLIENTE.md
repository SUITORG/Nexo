# MANUAL CLIENTE — SuitPawBook

**Para qué sirve este manual:** cómo usar PawBook como groomer.
**Audiencia:** el groomer dueño de la cuenta.

1. **Alta:** te damos acceso; cargas tu servicio base (baño/secado $X, raza grande $Y).
2. **Mascotas:** cada perro = un perfil (nombre, raza, teléfono del dueño, vacunas y notas).
3. **Reservas:** eliges mascota, fecha, hora, servicio y precio. El sistema calcula el depósito (30% default) — tú lo cobras a mano (Zelle/Venmo/efectivo) y lo marcas en la cita.
4. **Cancelaciones:** política default 24h=50% / <24h=100%. La cambias cuando quieras.
5. **Hoy:** abre "Hoy" y ves tu día completo con depósitos.

Regla de oro: sin depósito registrado, no hay reserva. El producto es la política.
