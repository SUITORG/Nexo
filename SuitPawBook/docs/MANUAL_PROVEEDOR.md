# MANUAL PROVEEDOR — SuitPawBook

**Para qué sirve este manual:** dar de alta un groomer/salón como cliente.
**Audiencia:** quien opera comercialmente PawBook.

1. Recopilar: nombre del negocio, teléfono WhatsApp, servicios base + precios, cuántas cabinas/personas.
2. Crear la cuenta (hoy: local `python/main.py`; futuro: alta multi-tenant).
3. Cargar las 5-10 mascotas más frecuentes con el dueño en la primera llamada (onboarding 30 min).
4. Enseñar la política default y ajustarla si el groomer quiere 48h o 100%.
5. Dejar marcado en el CRM: fecha de alta, plan, y primer check-in a los 14 días.
